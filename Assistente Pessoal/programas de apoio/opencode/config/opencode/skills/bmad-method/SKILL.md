# bmad-method

Agile AI-driven delivery that sizes process to the change: small fixes go straight
to build, complex work gets planning depth, context carries forward. Helenizado de
`bmad-code-org/BMAD-METHOD` (origem: https://github.com/bmad-code-org/BMAD-METHOD).

> Irmãs no catálogo: `spec-kit` (rígido), `onp-spec-driven`, `openspec` (fluido),
> `cc-harness-iai`. BMAD = o roteador right-sized + contexto durável.

## Quando usar

- Mudança pequena e clara → direto ao build (sem cerimônia)
- Iniciativa complexa → Clarify → Plan → Build → Learn
- Codebase herdada → estabelecer contexto verificado antes de mudar
- Time travado em "quanto planejar?" → rotear pelo tamanho da mudança

## Como usar

1. **Roteiar**: vaga→Clarify · grande e clara→Plan · pequena→Build+verify
2. **Executar**: `bmad-build` com a mudança; perspectivas (produto/arq/UX/dev/teste) quando ajudar
3. **Aprender**: Learn ajusta o próximo Plan; `bmad doctor` repara o runtime

## Princípio

Decisões explícitas, contexto durável (nunca re-explicar tudo por chat), mesmo método do protótipo ao sistema legado.
