# Memória Persistente Gran-Mestre

## Conceito
A memória persistente é o componente cognitivo que armazena informações de longo prazo.

## Estrutura
```
memoria/
├── decisoes/          # Decisões tomadas
├── aprendizados/      # Lições aprendidas
├── padroes/           # Padrões identificados
├── solucoes/          # Soluções encontradas
└── referencias/       # Referências técnicas
```

## Como usar
1. **Decisões**: Documentar decisões importantes com contexto e rationale
2. **Aprendizados**: Registrar lições aprendidas com exemplos
3. **Padrões**: Identificar padrões recorrentes em problemas
4. **Soluções**: Catalogar soluções para problemas comuns
5. **Referências**: Manter referências técnicas atualizadas

## Integração com Gran-Mestre
- Antes de qualquer task, verificar memória persistente
- Após decisões, atualizar memória
- Usar memória para evitar repetição de erros
