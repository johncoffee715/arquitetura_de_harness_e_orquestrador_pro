## Erros e Soluções

### Erro 1: sudo com senha interativa
- **Problema:** O terminal OpenCode não suporta entrada interativa de senha
- **Solução:** O usuário forneceu a senha (0000) e `echo "0000" | sudo -S` resolveu

### Erro 2: auto-detect de card com path `../pp_table`
- **Problema:** O script original hardcodava `card0` e o auto-detect usava `_pp="$_card/../pp_table"` que resolvia para `/sys/class/drm/card1/pp_table` (caminho errado)
- **Solução:** Corrigido para `_pp="$_card/pp_table"` — path correto é `/sys/class/drm/card1/device/pp_table`
- **Impacto:** Script não funcionava via systemd (que espera auto-detect)

### Erro 3: PP table stock size mismatch no backup
- **Problema:** O script antigo usava md5sum, a nova versão usa sha256sum
- **Solução:** Script atualizado com hash consistente

### Erro 4: upp_targets.conf perdido
- **Problema:** O `/tmp/upp_targets.conf` foi perdido entre sessões
- **Solução:** Recriado a partir dos valores confirmados no dump UPP

### Erro 5: Polkit/pkexec não configurado
- **Problema:** Tentativas de usar pkexec falharam (exit 127) — sem política para tee
- **Solução:** Descartado. sudo -S com password direto foi a solução

## Acertos

1. **UPP via `--from-conf`** em vez de múltiplas chamadas `set --write`
   - Mais atômico: 29 parâmetros em uma única transação
   - Menos risco de estado inconsistente
   - Reproductível via arquivo de configuração

2. **Auto-detect de card** em vez de hardcode
   - Funciona em qualquer sistema (card0, card1, etc.)
   - Evita erro de path que quebra o systemd service

3. **Backup automático** antes de cada escrita
   - Rollback trivial: `cat backup.bin > /sys/class/drm/card1/device/pp_table`

4. **TTY mode** documentado
   - Evita crash de vídeo que força reboot
   - Procedimento claro de rollback

5. **Hotspot em 150°C** — workaround para falso positivo do sensor 7nm
   - Delta Edge→Junction de ~50°C é anormal mas documentado em Vega20
   - Com watercooling e sem throttling, a leitura é confirmada falsa
   - Manter Edge como referência primária de temperatura

## Lições Aprendidas

1. **sysfs pp_table é root-only** — sem NOPASSWD ou interatividade, não há bypass
2. **UPP > hex edit manual** — offsets simbólicos validados contra a tabela real
3. **Sempre testar em TTY** — crash de GPU em X11/Wayland = reboot forçado
4. **Auto-detect é obrigatório** — card0 vs card1 varia por hardware/config
5. **Config file > linha de comando** — `--from-conf` garante reprodutibilidade
6. **systemd Before=lightdm.service** garante que a PP table esteja ativa antes do display manager
7. **Watercooling MI50:** Edge 34°C idle, 55°C load — sensor junction pode marcar 103°C sem throttling real
