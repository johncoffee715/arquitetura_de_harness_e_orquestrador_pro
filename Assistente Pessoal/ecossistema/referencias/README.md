# Referências Técnicas Gran-Mestre

## Estrutura
```
referencias/
├── hardware/          # Referências de hardware
├── software/          # Referências de software
├── documentacao/      # Documentação técnica
├── tutoriais/         # Tutoriais e guias
└── ferramentas/       # Ferramentas e utilitários
```

## Como usar
1. **Hardware**: Documentar especificações, limites, configurações
2. **Software**: Registrar versões, configurações, comandos
3. **Documentação**: Manter documentação técnica atualizada
4. **Tutoriais**: Catalogar tutoriais e guias práticos
5. **Ferramentas**: Listar ferramentas disponíveis e uso

## Integração com Gran-Mestre
- Consultar referências antes de implementar
- Atualizar referências após mudanças
- Usar referências para validar decisões
