# Mapa Cognitivo — Gran-Mestre Obsidian Vault

## Estrutura do Vault
```
ObsidianGranMestre/
├── cognicao/          # Documentação do sistema cognitivo
│   └── Cognicao-Gran-Mestre.md
├── sessions/          # Sessions salvas (memória de curto prazo)
│   ├── INDEX.md       # Índice das sessions
│   └── session_*.md   # Sessions individuais
├── memoria/           # Memória persistente (longo prazo)
│   └── README.md
├── referencias/       # Referências técnicas
│   ├── README.md
│   └── vega20-hardware.md
├── historico/         # Histórico de decisões
│   ├── README.md
│   └── decisoes-arquitetura-vega20.md
├── analise/           # Análises de dados
│   ├── README.md
│   ├── padroes-vega20.md
│   └── insights-vega20.md
└── .obsidian/         # Configuração do Obsidian
```

## Fluxo Cognitivo

### 1. Atenção (Foco)
- Verificar `sessions/` PRIMEIRO
- Buscar `memoria/` para decisões anteriores
- Consultar `referencias/` para documentação

### 2. Percepção (Contexto)
- Analisar sessão atual + histórico
- Identificar padrões em `analise/padroes-*.md`
- Gerar insights em `analise/insights-*.md`

### 3. Memória (Armazenamento)
- Salvar sessões em `sessions/`
- Atualizar `memoria/` com decisões
- Documentar em `referencias/`

### 4. Linguagem (Comunicação)
- Documentar em Markdown estruturado
- Usar tags para categorização
- Manter links entre documentos

### 5. Raciocínio (Decisão)
- Usar pipeline Gran-Mestre
- Consultar histórico antes de decidir
- Atualizar histórico após decisões

## Como Usar

### Para o Gran-Mestre
1. ANTES de qualquer task → verificar `sessions/` e `memoria/`
2. DURANTE a task → consultar `referencias/`
3. DEPOIS da task → atualizar `sessions/`, `memoria/`, `historico/`

### Para o Usuário
1. Abrir vault: `~/ObsidianGranMestre/`
2. Navegar por pastas temáticas
3. Usar busca do Obsidian (Ctrl+Shift+F)
4. Usar links internos `[[documento]]`
