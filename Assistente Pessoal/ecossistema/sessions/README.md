# Sessões Gran-Mestre

## Estrutura
Cada sessão é salva automaticamente pelo Gran-Mestre como memória persistente.

## Arquivos
- `session_YYYY-MM-DD_HH-MM-SS_ID.md` — Sessão individual
- Cada arquivo contém: data, ID, status, tags, conteúdo, aprendizados, decisões, referências

## Uso
1. **Salvar sessão**: `/home/johncoffee/obsidian-session-saver.sh save <session_id>`
2. **Listar sessões**: `/home/johncoffee/obsidian-session-saver.sh list`
3. **Buscar na memória**: `/home/johncoffee/obsidian-session-saver.sh search <query>`

## Tags
- `#session` — Sessão do Gran-Mestre
- `#gran-mestre` — Relacionado ao orquestrador
- `#cognicao` — Sistema cognitivo

## Cognição
As sessões são parte do sistema cognitivo do Gran-Mestre:
- **Atenção**: Verificar sessões antes de qualquer task
- **Memória**: Sessões são memória persistente
- **Raciocínio**: Analisar sessões para tomar decisões
