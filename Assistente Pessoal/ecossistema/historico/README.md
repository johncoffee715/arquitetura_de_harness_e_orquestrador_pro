# Histórico de Decisões Gran-Mestre

## Estrutura
```
historico/
├── decisoes/          # Decisões tomadas
├── mudancas/          # Mudanças realizadas
├── problemas/         # Problemas encontrados
└── solucoes/          # Soluções aplicadas
```

## Como usar
1. **Decisões**: Documentar decisões com contexto, alternativas e rationale
2. **Mudanças**: Registrar mudanças com antes/depois e impacto
3. **Problemas**: Catalogar problemas com sintomas e causa raiz
4. **Soluções**: Documentar soluções com implementação e resultado

## Integração com Gran-Mestre
- Consultar histórico antes de decidir
- Atualizar histórico após decisões
- Usar histórico para aprender com erros
