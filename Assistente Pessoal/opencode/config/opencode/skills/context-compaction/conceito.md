# Conceito (50-100 lines)
This is the main concept description for context compaction.

The context compaction skill is designed to efficiently summarize and organize large amounts of text context into a concise, structured format. This skill helps reduce cognitive load by extracting key ideas, maintaining logical flow, and preserving essential relationships between concepts.

Key aspects:
- Focus on core concepts and relationships
- Preserve essential details while removing redundancy
- Maintain logical structure and hierarchy
- Support for multi-lingual context (English, Portuguese, Spanish, etc.)
- Support for different formats (paragraphs, bullet points, lists, code blocks)
- Keep track of important entities, dates, names, and technical terms
- Generate structured output that's easy to review and use

Use cases:
- Summarizing long documents, reports, or technical papers
- Preparing briefing notes for presentations
- Creating concise summaries for knowledge management systems
- Organizing research notes and literature reviews
- Preparing for interviews or discussions where detailed context is needed
- Refining complex technical explanations for non-technical audiences
- Creating executive summaries from detailed reports

The skill follows best practices for context compaction:
- Preserves essential information without losing meaning
- Maintains logical structure and relationships
- Uses clear, concise language that's accessible to various audiences
- Respects different formats and formats (text, code, structured data)
- Works well with multi-language contexts
