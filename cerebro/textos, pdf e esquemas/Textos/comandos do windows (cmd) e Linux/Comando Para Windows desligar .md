# Comando Para Windows desligar 

 Shutdown -s -t 3600 timer para o Windows desligar após 3600 segundos.

Shutdown /s /t substitui o desligamento automático e aguarda a 
permissão do usuário para desligar.

Shutdown /s desligará o sistema instantaneamente.
3600=1h
1800=30 min
