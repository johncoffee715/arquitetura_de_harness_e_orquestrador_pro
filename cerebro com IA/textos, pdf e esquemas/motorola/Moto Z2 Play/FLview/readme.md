# readme

Just extract all files to a folder of your choice (e.g. c:\FLview). 

If the mentor versions sees cadence data, it will close itself and open the cadence version and vice versa.


On cadence data: 
FLview for cadence uses the same data which are used in motorola for DTM.

DTM uses for uploading:  http://dtm.mot.com/dtm_cimbridge/cad_drop/CAD_Deposit.pl?CadenceZip?NA? 
according to the format on top of the page (currently http://compass.mot.com/doc/141794846/valext.txt ) 
( process see http://compass.mot.com/doc/116685160/DTM_PC_Designer_Tutorial-CADENCE.pdf ).
